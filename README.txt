BRAVELY MADE MEDIA — WEBSITE FILES
==================================

QUICK START

1. Keep all files and folders together.
2. Replace logo.png with the finished logo. Keep the filename exactly logo.png.
3. Double-click index.html to preview the site.
4. Upload the complete folder to your web host when ready.


FILES

index.html   — Page structure and written content
styles.css  — Colors, layout, type, and responsive design
script.js   — Mobile menu, scroll effects, film viewer, and contact form
logo.png    — Temporary logo placeholder
assets/     — Existing public portfolio images from the current website


CONTACT FORM

Because this is a static website with no backend, the contact form opens a
ready-to-send message in the visitor's email app. Messages are addressed to:

bravelymademedia@gmail.com

EDITING TIPS

Use a plain text editor to make changes. Keep a backup before editing. Image
filenames are case-sensitive after the site is uploaded.
